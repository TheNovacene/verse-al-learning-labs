Privacy

This site listens to no signals.

The whole policy fits on one page, because there is almost nothing to disclose.

No cookies, no trackers

This site sets no cookies — none. It runs no analytics, no advertising, no marketing pixels, no fingerprinting, and embeds no third-party widgets. There is no consent banner because there is nothing to consent to.

Fonts served from here

The typefaces on this site (Fraunces and Inter, both open-licensed) are hosted on this site's own infrastructure. Visiting this site sends no requests to Google or any other font CDN.

Hosting

This site is served as static files from GitHub Pages. Like any web host, GitHub keeps short-lived server logs (including visitor IP addresses) for security and operational purposes; see GitHub's privacy statement. We have no access to, and keep no copy of, any visitor data.

Links elsewhere

Where this site links out — to booking, publishing or community platforms — those sites have their own privacy practices, which apply from the moment you arrive there.
